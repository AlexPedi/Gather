# Gather application icon

GatherIcon.png is the original raster artwork generated with the built-in image_gen tool. Its alpha channel is preserved. scripts/build-icon.sh produces all ten standard/Retina representations from 16 to 1024 pixels and packages Gather.icns into the application Resources directory during scripts/build-app.sh. CFBundleIconFile in scripts/Info.plist selects that resource. Generated previews and .icns files belong to the build output; this PNG remains the editable design source.

## Final generation prompt

Use case: logo-brand. Asset type: final native macOS application icon for Gather, a calm screenshot library that gathers and organizes images. Create one centered 1024 by 1024 square icon with genuine transparent outside margins. Icon silhouette: a polished macOS rounded square/squircle tile occupying about 88% of canvas width, rich violet (#7043E8) with restrained luminous lavender gradient, subtle bevel and soft dimensional depth. Main symbol: three clean ivory / pale lavender screenshot cards gathered in a small offset stack, the front card upright with elegantly rounded corners and a tiny minimal landscape glyph inside it (one lavender mountain and small circular sun); two cards subtly offset behind the front card to convey collecting and organization. Large bold readable symbol, beautiful at small Dock sizes. Premium restrained native macOS app icon, front-on, balanced, minimal, soft studio lighting. No letters, no text, no wordmark, no watermark, no surrounding mockup, no additional floating objects. Outside the tile must be transparent, never a white square or checkerboard. Avoid excessive glass, sparkling effects, tiny interface details or a large cast shadow.
